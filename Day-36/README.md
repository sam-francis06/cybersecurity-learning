## About Day 36

Day 36 focused on strengthening practical offensive security skills through hands-on CTF challenges and binary analysis. The **Deja Vu** walkthrough on TryHackMe reinforced the methodology of reconnaissance, enumeration, exploitation, and privilege escalation. Two TryHackMe challenge rooms, **The Concierge Knows Too Much** and **Magician**, enhanced skills in web enumeration, information disclosure, file analysis, steganography, and forensic investigation. On CyLab Security Academy, completing **Picker I**, **Picker II**, and **GDB Test Drive** provided practical experience with binary exploitation concepts, debugging using GDB, reverse engineering fundamentals, and program analysis. Although no new PortSwigger Web Security Academy labs were completed today, the day's activities significantly improved practical CTF-solving, debugging, and exploitation skills.
