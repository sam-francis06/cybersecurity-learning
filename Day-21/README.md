## About Day 21

Day 21 focused on practical learning across web application security, Linux privilege escalation, CTF problem-solving, cryptography, and SQL injection.

The TryHackMe walkthrough rooms strengthened understanding of CSRF vulnerabilities, hands-on testing with intentionally vulnerable applications, and the enumeration methodology behind Linux privilege escalation. The TryHackMe challenge rooms reinforced enumeration and exploitation workflows, with Cat Pictures 2 offering the strongest multi-stage problem-solving practice of the three. The CyLab Security Academy challenges built on classical cryptography skills, covering rotation and substitution ciphers along with basic RSA concepts.

The strongest technical progression of the day came from the PortSwigger SQL injection labs. Completing three sequential UNION-based labs — from identifying text-compatible columns, to retrieving data from other tables, to combining multiple values into a single output column — built a clearer understanding of the complete UNION-based exploitation workflow.

**SQL Injection Learning Progression**

```text
Determine the number of columns
        ↓
Identify text-compatible columns
        ↓
Construct valid UNION SELECT queries
        ↓
Retrieve data from additional tables
        ↓
Extract useful database information
        ↓
Combine multiple values into a single output column
```
