## About Me

Hi, I'm **Francis Samuvel** — a B.Tech Information Technology student with a strong interest in cybersecurity, ethical hacking, and practical security research.

I believe cybersecurity is a skill built through **consistent, hands-on practice** rather than theory alone. This repository is my personal learning journal, where I document daily progress, practical exercises, CTF challenges, and the knowledge gained while exploring different areas of security.

My goal is to continuously sharpen my technical skills, strengthen my problem-solving ability, and build a solid foundation for a career in cybersecurity.

## About This Repository

This repository is a centralized collection of my cybersecurity learning. Rather than simply tracking completed challenges, it documents the full process behind them:

| Documented                          | Purpose                                                                 |
| ----------------------------------- | ----------------------------------------------------------------------- |
| **Daily learning progress**         | A timestamped record of what was learned and when.                      |
| **Hands-on labs**                   | Practical exercises completed across each platform.                     |
| **Platform-specific documentation** | Dedicated logs for TryHackMe, CyLab, OverTheWire, and future platforms. |
| **Knowledge bases**                 | Consolidated, reusable reference material by domain.                    |
| **Commands and tools**              | A quick-reference library built from real practice.                     |
| **Lessons learned**                 | Reflections that turn individual challenges into transferable skill.    |
| **Practical notes**                 | Working notes captured during active problem-solving.                   |

The goal is a long-term reference that reinforces concepts through documentation and continuous practice — not just a scoreboard of completed challenges.

<div align="center">

```
Learn → Practice → Document → Improve → Repeat
```

Every challenge solved, every room completed, and every concept learned contributes to a growing personal knowledge base — compounding in value with each cycle.
