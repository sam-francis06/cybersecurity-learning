## 🎯 Skills Practiced

| Skill Area | Description |
|---|---|
| **Enumeration** | Actively probing a target to uncover services, users, and configurations. |
| **Information Gathering** | Collecting initial data about a target before any active testing begins. |
| **Web Exploitation** | Identifying and exploiting vulnerabilities within web applications. |
| **HTTP Analysis** | Inspecting requests, responses, and headers to understand application behavior. |
| **Directory Enumeration** | Locating hidden endpoints and files not linked from the visible application. |
| **Linux Fundamentals** | Navigating and operating confidently within Linux environments. |
| **Password Attacks** | Attempting to compromise authentication through brute-force or cracking techniques. |
| **Basic Privilege Escalation** | Elevating access from a low-privileged foothold to higher-level system access. |
| **OSINT** | Leveraging publicly available information to support reconnaissance or investigation. |
| **Digital Forensics** | Analyzing artifacts to reconstruct events or uncover hidden evidence. |
| **Web Security** | Understanding and identifying common application-layer vulnerability classes. |
| **Critical Thinking** | Applying structured, methodical reasoning to overcome non-obvious obstacles. |
| **CTF Methodology** | A systematic, repeatable approach to solving Capture The Flag challenges. |

## 📖 Key Takeaways

- Successful CTF solving starts with thorough reconnaissance.
- Enumeration is often the most important phase of an assessment.
- Small clues can lead to complete exploitation chains.
- Every challenge improves analytical thinking and methodology.
- Maintaining notes helps reinforce techniques and build a reusable knowledge base.
