## 💡 Key Learning Outcomes

| Outcome | Description |
|---|---|
| **Web Application Security** | Recognizing and exploiting common application-layer vulnerability classes. |
| **SQL Injection** | Manipulating database queries via unsanitized input to read or alter data. |
| **Cross-Site Scripting (XSS)** | Injecting client-side scripts into trusted web contexts. |
| **Authentication & Authorization** | Distinguishing identity verification from access control, and exploiting failures in either. |
| **Linux Command-Line Skills** | Efficient, confident operation within Linux environments. |
| **Digital Forensics** | Extracting and interpreting artifacts from files, images, and logs. |
| **Reverse Engineering Fundamentals** | Reading disassembled or decompiled code to infer program behavior. |
| **Binary Exploitation Basics** | Understanding memory layout and control-flow manipulation in compiled programs. |
| **Cryptography** | Identifying weak encoding, hashing, or encryption and reversing it where possible. |
| **Enumeration Methodology** | Systematically identifying services, files, and configurations relevant to a target. |
| **Problem Solving** | Applying structured reasoning to ambiguous, multi-step challenges. |
| **CTF Techniques** | A repeatable approach: reconnaissance, analysis, exploitation, and documentation. |
