## About Day 20

Day 20 focused on strengthening practical cybersecurity skills through CTF challenges, cryptography exercises, and structured web application security labs.

The TryHackMe challenge rooms provided experience in enumeration, investigation, and exploitation techniques. The CyLab challenges strengthened cryptography and decoding skills, while the PortSwigger Web Security Academy labs introduced practical SQL injection techniques, including retrieving hidden data, bypassing authentication, and determining the number of columns required for UNION-based attacks.
