## About Day 25

Day 25 focused on strengthening reconnaissance and network analysis skills. The Nmap walkthrough reinforced host discovery, port scanning, service enumeration, and version detection techniques commonly used during penetration testing. The RootMe challenge provided hands-on experience with enumeration, exploitation, and Linux privilege escalation in a realistic CTF environment. The Shark on Wire 1 challenge enhanced packet analysis skills using Wireshark, improving the ability to inspect network traffic, identify protocols, and extract valuable forensic information from captured packets.
