## 📖 Overview

This document records my cybersecurity learning progress during the **first thirteen days** of my practical learning journey. The primary objective during this phase was to build a strong foundation in cybersecurity through hands-on labs, Capture The Flag (CTF) challenges, Linux practice, and real-world security concepts.

Rather than focusing solely on theory, this period was dedicated to solving practical challenges and documenting learnings across multiple cybersecurity platforms — establishing both technical grounding and a sustainable daily learning habit.

---

## 🎯 Objectives

| Objective | Purpose |
|---|---|
| **Develop Linux command-line proficiency** | The terminal underpins nearly every security tool and environment. |
| **Strengthen networking fundamentals** | Understanding protocols is prerequisite to both attack and defense. |
| **Learn web application security concepts** | Most real-world attack surfaces are web-based. |
| **Practice offensive and defensive techniques** | Building competence on both sides of the fight develops a complete security mindset. |
| **Improve problem-solving through CTF challenges** | CTFs simulate real engagements more closely than passive study. |
| **Build a structured knowledge base** | Documentation compounds in value and speeds up future work. |
| **Establish a consistent daily learning habit** | Long-term mastery depends on sustained, repeated practice. |
