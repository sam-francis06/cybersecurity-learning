## 🎯 Skills Practiced

| Skill Area                | Description                                                                                |
| ------------------------- | ------------------------------------------------------------------------------------------ |
| **Enumeration**           | Actively probing targets to identify services, users, endpoints, and configurations.       |
| **Information Gathering** | Collecting and analyzing information about targets before exploitation.                    |
| **Web Exploitation**      | Identifying and exploiting vulnerabilities within web applications.                        |
| **HTTP Analysis**         | Inspecting HTTP requests, responses, headers, parameters, and application behavior.        |
| **Directory Enumeration** | Discovering hidden files, directories, endpoints, and application resources.               |
| **Linux Fundamentals**    | Navigating Linux environments and using command-line tools effectively.                    |
| **Password Attacks**      | Practicing password cracking and authentication testing techniques within authorized labs. |
| **Privilege Escalation**  | Identifying weaknesses that allow access to higher system privileges.                      |
| **OSINT**                 | Using publicly available information to support investigations and reconnaissance.         |
| **Digital Forensics**     | Examining digital artifacts to identify evidence and reconstruct events.                   |
| **Web Security**          | Understanding and exploiting common application-layer vulnerabilities.                     |
| **Critical Thinking**     | Applying structured reasoning to investigate and solve unfamiliar challenges.              |
| **CTF Methodology**       | Developing systematic and repeatable approaches to cybersecurity challenges.               |

## 📖 Key Takeaways

* Successful challenge solving begins with thorough reconnaissance and enumeration.
* Enumeration is often the most important phase of a penetration testing challenge.
* Small clues and overlooked details can lead to complete exploitation chains.
* Solving different challenge categories improves technical adaptability and analytical thinking.
* Maintaining structured notes helps reinforce techniques and creates a reusable cybersecurity knowledge base.
* Independent challenge solving is an important indicator of practical progress beyond guided walkthrough completion.
