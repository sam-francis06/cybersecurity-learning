## 📖 About

This repository documents my practical cybersecurity learning journey on **CyLab Security Academy**, a platform offering hands-on Capture The Flag (CTF) challenges designed to strengthen applied security skills across multiple domains — Web Exploitation, Digital Forensics, Reverse Engineering, Cryptography, Binary Exploitation, Artificial Intelligence, and General Security.

The purpose of this documentation is threefold:
1. **Track progress** across difficulty tiers and challenge categories.
2. **Organize acquired knowledge** into a structured, searchable reference.
3. **Maintain a long-term learning journal** that captures methodology, not just outcomes.

---

## 🎯 Objectives

| Objective | Purpose |
|---|---|
| **Develop practical cybersecurity skills** | Move beyond theory into applied, hands-on capability. |
| **Improve analytical and problem-solving ability** | CTF-style challenges reward structured reasoning over memorized steps. |
| **Practice real-world attack and defense techniques** | Build familiarity with the same methods used in professional engagements. |
| **Strengthen Linux and command-line proficiency** | The terminal remains the primary interface for nearly all security tooling. |
| **Learn secure coding concepts** | Understanding how vulnerabilities are introduced aids in preventing them. |
| **Build experience with CTF methodology** | A repeatable process (recon → analyze → exploit → document) speeds up future challenges. |
| **Maintain structured documentation** | A well-organized knowledge base compounds in value with every challenge solved. |

## 🎯 Skills Developed

| Skill | Description |
|---|---|
| **Enumeration** | Systematically identifying services, files, and configurations relevant to a target. |
| **Web Application Security** | Recognizing and exploiting common application-layer vulnerability classes. |
| **SQL Injection** | Manipulating database queries via unsanitized input to read or alter data. |
| **Cross-Site Scripting (XSS)** | Injecting client-side scripts into trusted web contexts. |
| **Server-Side Vulnerabilities** | Exploiting flaws in backend logic, file handling, or request processing. |
| **Client-Side Vulnerabilities** | Exploiting flaws that execute or manifest within the user's browser. |
| **Authentication & Authorization** | Distinguishing identity verification from access control, and exploiting failures in either. |
| **Linux Command-Line Usage** | Efficient, confident operation within Linux environments. |
| **Cryptography** | Identifying weak encoding, hashing, or encryption and reversing it where possible. |
| **Reverse Engineering Fundamentals** | Reading disassembled or decompiled code to infer program behavior. |
| **Binary Exploitation Basics** | Understanding memory layout and control-flow manipulation in compiled programs. |
| **Digital Forensics** | Extracting and interpreting artifacts from files, images, and logs. |
| **Problem Solving** | Applying structured reasoning to ambiguous, multi-step challenges. |
| **CTF Methodology** | A repeatable approach: reconnaissance, analysis, exploitation, and documentation. |
