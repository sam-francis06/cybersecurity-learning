## About Day 22

Day 22 focused on strengthening practical web application security skills, particularly Burp Suite request manipulation and advanced SQL injection techniques. Activities included TryHackMe walkthrough and challenge rooms, CyLab Security Academy challenges, and PortSwigger Web Security Academy SQL injection labs.

Day 22 marked the completion of 300 practical cybersecurity learning activities. The main focus was SQL injection, progressing from database enumeration and fingerprinting techniques to blind SQL injection attacks using conditional responses. Working with Burp Suite Repeater also strengthened the ability to manually inspect, modify, and resend HTTP requests, an essential skill for web application security testing.

**Key Learnings**

- Practiced using Burp Suite Repeater to manually modify and resend HTTP requests, improving understanding of request manipulation and response analysis.
- Identified vulnerabilities and worked through exploitation in the Speed Chatting challenge room.
- Applied multiple cybersecurity concepts and techniques to discover hidden flags in c4ptur3-th3-fl4g.
- Strengthened problem-solving, investigation, and CTF methodology through the CyLab challenges.
- Enumerated database tables and columns by querying database metadata using SQL injection.
- Identified database type and version information on MySQL and Microsoft SQL Server through SQL injection.
- Exploited blind SQL injection vulnerabilities by analyzing conditional response differences.

**Skills Practiced**

- Burp Suite Repeater
- HTTP Request Manipulation
- Web Application Security Testing
- SQL Injection / UNION-Based SQL Injection
- Database Enumeration and Fingerprinting
- Blind SQL Injection and Conditional Response Analysis
