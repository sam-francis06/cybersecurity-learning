## About Day 28

Day 28 focused on Windows exploitation, web application security, Linux privilege escalation, cryptography, and digital certificate analysis. The Blue walkthrough provided hands-on experience exploiting the MS17-010 (EternalBlue) vulnerability using Metasploit while reinforcing SMB enumeration and post-exploitation techniques. The TryHackMe challenge rooms strengthened skills in XML External Entity (XXE) attacks, authentication bypass, Linux enumeration, and privilege escalation. The CyLab Security Academy challenges expanded foundational knowledge of digital certificates, public key infrastructure (PKI), and classical cryptographic techniques including Rail Fence and transposition ciphers, enhancing both offensive security and digital forensics capabilities.
