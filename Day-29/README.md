## About Day 29

Day 29 focused on modern web authentication security and cryptographic analysis. Three PortSwigger Web Security Academy labs provided hands-on experience exploiting JSON Web Token (JWT) implementation flaws, including authentication bypass through unverified signatures, flawed signature verification, and weak signing keys. The TryHackMe challenge rooms strengthened practical web exploitation, enumeration, privilege escalation, and Capture The Flag problem-solving skills. Additionally, the CyLab Security Academy challenges reinforced image-based analysis techniques and RSA cryptography by applying Pollard's factorization algorithm, further improving practical cryptanalysis and web security knowledge.
