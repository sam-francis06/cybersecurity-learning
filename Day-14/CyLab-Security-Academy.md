## Completed Challenges

### SOAP

**Category:** Web Security
**Focus Area:** XML and Web Services Security

**Overview**

This challenge focused on analyzing a web application that processes XML-based requests and identifying security weaknesses related to improper XML handling, providing practical experience in understanding how insecure XML processing can expose sensitive information or application resources.

**Skills Practiced**

- Web application analysis
- XML structure analysis
- HTTP request inspection
- Input manipulation
- Web security testing
- Vulnerability identification

**Key Takeaways**

- XML-based applications require secure parser configurations.
- User-controlled XML input should always be treated as untrusted data.
- HTTP requests should be carefully inspected to understand how applications process submitted information.
- Improper XML processing can introduce serious security vulnerabilities.
- Understanding application behavior is essential before attempting exploitation.

### Trickster

**Category:** Web Security
**Focus Area:** Web Exploitation

**Overview**

This challenge focused on investigating a vulnerable web application and identifying weaknesses within its functionality and implementation, requiring systematic enumeration, analysis of application behavior, and practical problem-solving to identify the intended attack path.

**Skills Practiced**

- Web reconnaissance
- Content discovery
- Application enumeration
- HTTP analysis
- Web exploitation
- Analytical problem-solving

**Key Takeaways**

- Thorough enumeration should be performed before attempting exploitation.
- Hidden files, directories, and application functionality can reveal valuable information.
- Application responses may provide clues about internal implementation.
- Web challenges often require combining multiple pieces of information.
- Structured investigation is more effective than randomly testing vulnerabilities.

---

### More SQLi

**Category:** Web Security
**Focus Area:** SQL Injection

**Overview**

This challenge focused on identifying and exploiting SQL injection vulnerabilities within a web application, reinforcing the importance of understanding how user-controlled input interacts with backend database queries and how insecure query construction can lead to unauthorized data access.

**Skills Practiced**

- SQL injection testing
- Input analysis
- Authentication testing
- Database interaction
- Web application exploitation
- Query manipulation

**Key Takeaways**

- SQL injection occurs when applications improperly handle user-controlled input within database queries.
- Understanding application responses can help identify injectable parameters.
- Different SQL injection scenarios may require different testing approaches.
- Authentication mechanisms can become vulnerable when database queries are constructed insecurely.
- Secure applications should use parameterized queries and proper input handling.

## Day 14 Takeaways

- Web security challenges require a strong understanding of application behavior.
- XML processing can introduce vulnerabilities when parsers are configured insecurely.
- Thorough enumeration remains one of the most important stages of web exploitation.
- SQL injection requires understanding how application input interacts with backend queries.
- Different challenges require adapting techniques rather than relying on a single exploitation methodology.
- Consistent CTF practice improves technical investigation and independent problem-solving skills.
- Documenting challenge experience helps reinforce methodologies and build a reusable cybersecurity knowledge base.
