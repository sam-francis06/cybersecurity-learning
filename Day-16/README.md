## About Day 16

Day 16 focused on strengthening practical cybersecurity skills through security analysis, vulnerability chaining, Local File Inclusion, server-side vulnerability analysis, OSINT, cryptographic analysis, encoding and decoding, and restricted shell exploitation.

**Key Learnings**

- Studied the responsibilities and workflows associated with senior-level security analysis and SOC operations.
- Practiced combining multiple vulnerabilities to develop more impactful attack paths.
- Performed reconnaissance, enumeration, hash cracking, and privilege escalation on Linux systems.
- Identified and exploited a Local File Inclusion vulnerability through path traversal and parameter manipulation.
- Analyzed server-side application behavior to identify a Markdown-to-PDF processing vulnerability.
- Applied OSINT techniques to gather and correlate publicly available information.
- Practiced cryptographic analysis and encoding/decoding techniques to solve independent challenges.
- Investigated restricted shell environments and executed commands using shell variables to bypass command filtering.

**Tools and Technologies Used**

- Nmap
- Linux / Kali Linux
- Web Browser Developer Tools
- Command-Line Interface
- Cryptographic Analysis Tools
- OSINT Techniques
